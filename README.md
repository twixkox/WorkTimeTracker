# WorkTimeTracker

Веб-приложение для учёта рабочего времени и трудозатрат производственных подразделений.
Позволяет сотрудникам заполнять табели, мастерам — проверять и утверждать их, а руководству —
получать сводные отчёты и аналитику по участкам.

## Основные возможности

- Заполнение дневных и недельных табелей, учёт времени смены и внутрицеховых работ.
- Распределение трудозатрат по сотрудникам, подразделениям, катерам и видам работ.
- Согласование табелей с комментариями, историей изменений и журналом аудита.
- Личные кабинеты сотрудников, мастеров, начальника производства и администратора.
- Сводки, дашборды, отчёты и экспорт данных в Excel.
- Импорт сотрудников, управление справочниками, ролями и составом подразделений.
- Внутрисистемные уведомления и контроль незаполненных табелей.
- Адаптивный интерфейс для компьютеров, планшетов и смартфонов.

## Стек

- **C#, .NET 8, ASP.NET Core Razor Pages** — серверная часть и страницы приложения.
- **Entity Framework Core** — работа с данными и миграции.
- **Microsoft SQL Server / SQLite** — варианты хранения данных.
- **ASP.NET Core Identity** — учётные записи, аутентификация и роли.
- **Bootstrap 5, JavaScript, Chart.js** — интерфейс и графики.
- **ClosedXML** — импорт и экспорт Excel.
- **xUnit** — автоматические тесты.
- **Docker, Docker Compose** — контейнерное развёртывание.
