# ⏱️ WorkTimeTracker — учёт рабочего времени и трудозатрат

Веб-приложение для производственных подразделений на **ASP.NET Core Razor Pages**. В нём есть:
- дневные и недельные табели;
- учёт работ по катерам, участкам и видам работ;
- согласование табелей и история изменений;
- отчёты, дашборды и экспорт в Excel;
- уведомления, роли и административная панель.

## Возможности

### Для сотрудников
- **Дневной табель.** Начало и окончание смены, затраченное время, номер катера и описание выполненных работ.
- **Недельный режим.** Для отдельных участков доступен табель сразу за всю неделю.
- **Упрощённый режим.** Склад и водители указывают только время смены, без строк трудозатрат и согласования.
- **Черновики.** Табель можно сохранить, вернуться к нему позже и отправить на проверку после завершения.
- **История.** Просмотр прошлых табелей, статусов и комментариев мастера.
- **Подсказки.** Автоматический расчёт продолжительности смены, вычет обеда и предупреждения о переработке.

### Для мастеров участков
- Табели сотрудников своего участка и собственный табель в разделе «Мой табель».
- Проверка суммы часов, переработок и незаполненных сведений.
- Утверждение и отклонение табелей с комментарием.
- Редактирование с записью действий в журнал аудита.
- Сводка по катерам и загрузке участка.
- Экспорт данных участка в Excel и печатная форма табеля.

### Для начальника производства
- Все подразделения, сотрудники и табели в едином интерфейсе.
- Сводные отчёты по трудозатратам, катерам и участкам.
- Дашборды с распределением и динамикой рабочего времени.
- Утверждение и отклонение табелей, включая двухступенчатую схему согласования.
- Экспорт производственных отчётов в Excel.

### Для администратора
- Управление пользователями, ролями и привязкой сотрудников к учётным записям.
- Справочники подразделений, сотрудников, катеров и видов работ.
- Управление составом подразделений и параметрами расчёта рабочего времени.
- Импорт сотрудников из Excel.
- Журнал аудита действий и системный журнал с разделением по уровням.
- Доступ ко всем отчётам и производственным разделам.

### Уведомления
- Внутрисистемные уведомления о событиях и изменениях табелей.
- Контроль сотрудников без табеля за рабочий день.
- Сводное уведомление мастера участка после окончания смены.

## Роли

| Роль | Основные возможности |
|---|---|
| **Employee** | Заполнение своего табеля, черновики, отправка на согласование, история |
| **SectionMaster** | Табели своего участка, проверка, согласование, сводки и экспорт |
| **ProductionHead** | Все участки, производственная аналитика, отчёты и согласование |
| **Admin** | Пользователи, справочники, настройки, аудит, журналы и все отчёты |

## Workflow табеля

```text
Черновик → На утверждении → Утверждён
    ↑             |
    └─────────────┴─ Отклонён с комментарием
```

Основные правила:
- время обеда автоматически вычитается из продолжительности смены;
- сумма трудозатрат не может превышать отработанное время;
- окончание смены раньше начала не допускается;
- для работ по катеру обязательны его номер и описание;
- дробные часы можно вводить с точкой или запятой;
- переходы по статусам и редактирование после отправки попадают в аудит.

## Установка и запуск

### Через Docker

```bash
git clone https://github.com/twixkox/WorkTimeTracker.git
cd WorkTimeTracker
cp .env.example .env
```

Заполните локальный файл `.env`, затем выполните:

```bash
docker compose up --build
```

Сайт будет доступен по адресу `http://localhost:8080`. База SQLite и данные приложения
сохраняются в Docker-томе.

### Локально с SQLite

1. Установите [.NET 8 SDK](https://dotnet.microsoft.com/download) или более новый совместимый SDK.
2. Запустите приложение:

```bash
cd src/WorkTimeTracker
dotnet run
```

3. Откройте адрес из вывода команды, по умолчанию `http://localhost:5000`.

База SQLite и начальные справочники создаются автоматически. Для использования Microsoft SQL Server
предусмотрены `appsettings.MSSQL.json` и скрипт `db/001_create_and_seed.sql`.
